# 泄漏↔修复对照示例

> Provenance：蒸馏自 deepseek-harness `dsh-trim-cot-leakage/references/examples.md`（MIT，2026-09-10）；示例全部改写为本仓表面（ADR / HANDOFF / capsule 问题池 / 引擎代码），并按本仓体裁校准——本仓的设计稿、蓝图、问题池均已提交，§ 与里程碑引用多数有主，死引用判据按「HEAD 可解析」不按模式形态。

用途是认准管辖原则，不是抄模板。本文件刻意引用泄漏措辞作校准材料——[扫描电池](recall-batteries.md)默认排除本技能目录，这里的措辞不构成他处使用许可。

## 死引用

### 有主的决策——按名 + 路径引用

**泄漏：**「references 实拆按 B0 拍板执行（件 4）。」

**修复：**「references/ 实拆按 [B0 框架结构 ADR 件 4](../../../notes/implemented/architecture/2026-09-08-b0-framework-structure.md) 执行：触发条件 = 正文超预算或需携带模板/清单。」

序号「件 4」是裸序号——HEAD 可检索，但不点名 owning ADR。按名 + 路径引用 owning ADR（表面支持链接就落链接），后续提及可用可检索名。

### 无主的决策——命题自立

**泄漏：**「基因入档以事件为原子（决策 7：事件即事实）。」

**修复：**「基因入档以事件为原子单位。」

没有已提交物拥有「决策 7」，引文删除——但事实子句（事件即事实）重述到自立，不连带删除。

### 会话速记审计号

**泄漏：**「投影是纯记录（R3 旁证）。」

**修复：**「投影是纯记录。」

仓库里没有叫「R3 旁证」的已提交物；这是评审会话速记，零命题。对照：ADR 头部的 `Review: FULL/…/R1=ok` 证据行是裁定过的槽位，合法。

### 无主的 § 与阶段标签

**泄漏：**「收口按新方案 §3.1 的顺序走（T2 批之后）。」

**修复：**「收口顺序见流程卡 [feature-flow](../../../workflows/feature-flow.md)：ADR → 实现 → 门禁 → 评审。」

没有已提交草稿拥有「新方案 §3.1」和「T2 批」，删引用、用已提交主替代。对照：「问题池 §3.4（谱系）」「问题池 §2.2-6」有已提交主（[capsule 问题池](../../../../docs/research/capsule-01-optimization-round.md)）且自有编号——按节引用合法；外部标准（RFC §10.1.5）在仓外自解析，保留。判据是 HEAD 可解析，不是模式形态。

## 批次视角落进 durable 面

本仓的泄漏高频形态：变更叙事的家在 journal 月卷与 HANDOFF 滚动窗，泄漏 = 叙事落进 durable 文档。根 [AGENTS.md](../../../../AGENTS.md)「文档纪律」拥有该原则（写当前状态，不写变更史），本技能应用它。

**泄漏（durable 体）：**「review-tier 曾放行任一 implemented ADR 搭证据车，现已收紧为须由本变更引入。」

**修复：**「Review 证据行须由本变更引入——旧 ADR 不搭车（[evidence-ride-along ADR](../../../notes/implemented/bug-fix/2026-09-10-review-tier-evidence-ride-along.md)）。不收紧则 FULL 变更可搭同批旧 ADR 的证据行过闸。」

当前规则现在时陈述；修掉的回归写成现在时反事实钉。「曾/现已」把规则钉在仓库考古上。

## 对冲与无主推迟

**泄漏：**「泛化面随下次发版处理。」

**修复：**「余项 = 泛化到按文件所属仓找 lint 配置（家：capsule 问题池 §2.1「规范事前接入」，[capsule 问题池](../../../../docs/research/capsule-01-optimization-round.md)）。」

推迟必须有家（问题池/HANDOFF-todos 条目或 `TODO(name):`）；没有 owner 的对冲就是计划残留，升格或删除，不保留对冲原样。

## 评审编舞

**泄漏（durable 体）：**「评审 R2 抓回扫描正则失配，本批已修。」

**修复：**「防火墙扫描正则须匹配 `.mjs` 发射形态并带非空守卫。」抓住的过程落 journal 月卷。

对照：ADR 的 Review 证据行是裁定槽位，不是编舞。

## 面向评审者的自我辩护

**泄漏（注释）：**「这个 cast 是安全的——构造方只是没把 optional 声明严格。」

**修复：**「构造方填充全部 optional 字段；声明类型比运行时保证松。」陈述维护者不可破坏的不变量；不变量在码里可见就删注释。「它 simply…」是在回答 HEAD 上没人提出的异议。

## 复述与推导

**泄漏（注释）：**「先归一化标签，再截断，再包装。」——下面三行代码说的同一件事，删。

**泄漏（测试）：**「本测试先建会话，发两条消息，等第二条回复，再断言日志有四条。」→「两次往返必须恰好产出四条日志——投影对共享前缀去重。」只留非显然的断言理由。

## 写作语言混杂（本仓方向：中文正文夹半翻译工作语）

**泄漏：**「这批把 lint 反馈 fix 在写码循环里，review 还没过。」

**修复：**「写码当轮 lint 拦回已落地；评审收口后转 implemented。」

半翻译的工作对话是转写残留。对照：术语（gate / ADR / skill / rank / kebab 名）是本仓约定词汇，不是残留——判据是有没有中文等价物且翻译不损义。

## Keeps（增量判据）

keep 判据的单源 = [SKILL.md「什么不是泄漏」](../SKILL.md)（issue 引用 / ADR 内 PR 引用 / 抑制理由 / 现在时反事实 / 实测边界 / 运行时新旧 / 体裁形式）；本节只列 SKILL.md 未覆盖的增量：

- **体裁自带的叙事槽**——journal 月卷 / HANDOFF 滚动窗 / postmortem / ADR 拍板轨迹 = 变更史的家，叙事留在原地；可疑只在叙事泄漏进 durable 面。
- **ADR 的 Review 证据行**——`Review: FULL/…/R1=ok` 是机器判定的裁定槽位，不是评审编舞。

## 过度纠偏陷阱

以下每个陷阱在清理轮都真实翻过车。动刀前先枚举段落的命题（[noo-prose-standard](../../noo-prose-standard/SKILL.md)）。

### 义务翻成背书

**原：**「护栏三件（token-meter / 严格改进度量 / canary）是延后收口的例外——触发时须转 implemented 并修正骨架 ADR 归口。」
**纠过头：**「护栏三件是认可的延后例外。」
**修复：** 保留原句。「延后收口/触发时须」是义务（guardrail-defer-trigger ADR 在案），「认可」给现状盖章——缩短同时翻转了模态。

### 假设升成已落地

**原：**「官方 sessionHeader（上游 pi#9326）落地后，`dsh-opencode-session` 插件退役、settings 死块清理。」
**纠过头：**「官方 sessionHeader 已落地，`dsh-opencode-session` 插件已退役。」
**修复：** 保留未来标记或显式「（假设件，上游尚未落地）」——只删未来标记，把挂起条件变成装机声明。

### 连带真事实一起删

**原：**「gates.json 的 cmd 行叙述了门禁的运行方式；cmd 也是钩子与 CI 消费的发射单源。」
**纠过头：** 整句当叙述删。
**修复：**「cmd 是钩子与 CI 消费的发射单源（engine/gates.json）。」半句是叙述、半句是承重耦合——命题共享一行时删子句不删句子。

### 丢出处留数字

**原：**「架构规范零环结论是实测的：import 边全扫 n=46/81。」
**纠过头：**「零环：46 个文件、81 条 import 边。」
**修复：** 保留「实测」。没有它，观察读成定义，没人会在代码面扩张后重测。
