# 散文三分对照示例

> Provenance：蒸馏自 deepseek-harness `dsh-prose-standard/references/examples.md`（MIT，2026-09-10）；三分对照（砍过头/均衡/写过头）全部改写为本仓表面（技能 / cookbook / ADR / 引擎与适配层代码 / 门禁失败文案 / 基因注入文本）。

用途是认准管辖原则，不是抄模板。「均衡」= 该位置承重的命题全部存活、解释恰好够用。**词数变小本身不是改进。**

## 保住每个事实子句

**原文：**「适配层把宿主 exec 载荷的 `arguments` 字段投影为策略输入；启动时校验宿主 API 键存在且形状相容；发布前断言包面不变量。」
**砍过头：**「适配层投影宿主载荷。」
**均衡：** 原句。
动作主体、载荷字段名、两个校验时点、两份断言对象是分立事实——砍装饰不砍命题。

## 显式范围行是功能件

**砍过头：**「读源文件，凭判断。」
**均衡：**「本技能是引导不是脚本。点名检查之外凭判断；已文档化的要求仍然适用。」
**写过头：** 数段文字论证清单为何不能替代独立推理。
显式限制改变 agent 怎么走工作流，是承重命题；重复的劝说才是赘肉。

## cookbook 条目保动作与验证

**砍过头：**「给工具加测试。」
**均衡：**「单测覆盖注册与处置；从真实装载路径打一遍工具；渲染输出变化时补快照。断言观测外部结果，不是模型自报。」
**写过头：** 逐夹具文件、逐断言复述示例代码已可见的一切。
保留测试分层、必需动作、真实入口路径、可观察验证；夹具叙述删。

## 保所有权与时序

**砍过头：**「门禁按依赖图并行。」
**均衡：**「门禁在全部 `needs` 前置通过后才启动；前置红或被 skip 则下游 skipped，skip 理由沿 needs 链传染。」
**写过头：** 逐调度轮、逐 Promise 复述 runner 内部。
谁先谁后、失败怎么传导、跳过怎么传染——钩子/CI 消费方可见的契约事实。

## 触点提醒注释保生命周期语义

**砍过头：**「提醒技能触点。」
**均衡：**「tool-pre 按路径模式判「该载未载」，经 `agent.inject` 注入一行 advice；同一触点重复出现不重提，技能载入后消失。」
触发条件、注入通道、去重边界、消失条件——策略消费方可见行为，不是实现叙述。

## 定位复杂代码但不复述它

**砍过头：**「门禁 DAG runner。」
**均衡：**「解析门禁图并按 `needs`/`after` 有界并行执行（默认并行度 min(CPU, 8)）；重 id、未知依赖、环等坏图 fail-closed exit 2。例外机制的家在 gates.mts 头注。」
**写过头：** 逐类逐 helper 预览下方代码。
保留模块角色、依赖、职责、非显然生命周期；架构理由链接，局部控制流让代码自己说。

## 公共 API 契约注释保失败

**砍过头：**「跑门禁。」
**均衡：**「`--run` 执行门禁并聚合退出码：0 全绿 / 1 有门禁红 / 2 fail-closed（清单缺失、坏条目、坏图、坏槽位、未知 skip）。」
**写过头：** 内部状态机分支与通往每次退出码的精确 helper 链。
退出码语义是钩子/CI 消费方的契约事实。

## 链接理由但保本地契约

**砍过头：**「发布面契约见 track-b ADR。」
**均衡：**「发布前断言包面不变量：`main`/`exports` 每个目标实存且被 `files` 覆盖、dist 关键件在位、白名单外目录禁入；缺 dist fail-closed。陈旧 dist 可能假绿的裁决见 [track-b ADR](../../../notes/implemented/architecture/2026-09-08-coding-enforcement-track-b.md)。」
**写过头：** 在每个断言旁复述 ADR 的否决模型与演化史。
发版流程需要的行为与失败模式留在原地；依据与理由链接。

## implemented ADR 保验证契约

**砍过头：** ADR 落地后整节删 Testing。
**均衡：**「单测覆盖发布前后取消、处置静默、provider 重载。构建产物 smoke 覆盖真实装载路径；快照覆盖推迟（传输进程私有）。」
**写过头：** 逐文件夹具与断言清单，无额外行为区分。
删迁移任务与测试叙述；保分层、钉住的行为、真实入口、点名覆盖缺口。

## 安全边界给一个具体例子

**砍过头：**「挂载插件共享宿主权限。」
**均衡：**「挂载插件共享宿主权限；例如拿到宿主命令执行入口，即可以宿主权限起任意进程。」
**写过头：** 列每个可滥用服务与每个假想漏洞。
抽象限制配一个操作性例子就够。

## 推理转写整个删掉

**写过头：**「先看值是否缺失；缺失则下个分支提前返回；否则继续——所以最终断言安全。」
**均衡：** 代码已表达这些分支时不写注释；非显然不变量受保护时只陈述该不变量。
不要把推理转写压短成更短的叙述——删。

## 配置注释解释树说不出的顺序后果

**写过头：**「本条先载本地 fs provider，再载策略插件，再载读/写/编辑工具」——相邻条目已展示该顺序。
**均衡：**「策略件先于写类工具装载，写调用才能先过读后写检。」
保顺序的后果、意外的作用域规则、安全边界；清单让配置自己报。

## 模型可见文本守归属

**砍过头：**「调用失败时工具返回错误。」
**写过头：** 把别的包的 schema 与渲染文案抄进本 README。
**均衡：** 引用本包拥有的稳定 prompt/结果/错误文本；schema 链接生成目录、他包文案链接消费方 README；本地只陈述本包的条件与增量。
到模型眼前的措辞是行为，但重复会漂移——精确性归 owner。纯散文审计发现可疑措辞而没有 owning 可运行快照时，不静默改——留原样报告推迟，或把 owner 场景扩进授权范围。

## 生成摘要独立成立

**砍过头：**「审批请求与策略服务。」——owner 后文解释策略顺序与审计，但目录只导出第一句。
**写过头：** 把服务全生命周期搬进被抽取的句子。
**均衡：**「审批服务：在 answerer 之前施加会话策略，把每次 ask/结果对记入请求会话。」
知道生成器抽取什么——被抽取片段必须保住生成面上的契约（本仓实例：技能目录面 ≤500 字摘要）。

## 限制是契约不是债务清单

**砍过头：** 漏写「进程生命周期缓存使配置变更需重载插件」。
**写过头：** 列私有 helper 清理与无调用方的 test-only 访问器。
**均衡：**「provider 选择缓存于插件生命周期；安装或修复 provider 需重载。」
影响使用或安全维护的缺口保留；普通清理进 `TODO` 或 ADR。README 不是积压倾倒场。

## 不为字数单独砍

**现句：**「适配器把 provider 错误归一为共享错误类型，调用方因此能统一处理鉴权、限流与瞬时失败。」
**更短但更差：**「适配器归一 provider 错误。」
**裁决：** 若链接或周边契约已列失败类目则砍；否则保现句——短版丢了后果与区分，结构没有变好。
