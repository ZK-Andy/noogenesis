## Problem

立项 ADR B5 行只定范围（gates.json cmd 重指、删 py/sh/旧 js 源、CI 面更新、发版 0.2.0），切换细节未立项。并存期终点（2026-09-08）实盘：

- **门禁面**：gates.json 十三条 cmd 中十条为 `python3`/`bash`；py 权威件 13 件（verify-* ×10 + gates.py + gen-manifest.py + mdref.py）+ change-scope.sh 在库；`reconcile-b1.mts` / `reconcile-b2.mts` 双跑对账临时代件在库；CI self-test 双列（py 权威列 + TS 列）、engine/adapter self-test 双列（js 源 + dist）。
- **引擎与适配层**：engine 10 件 .js、adapters/dsh 9 件 .mjs 与 TS/dist 并存（B2 起 npm 发布面已切 dist，源 js/mjs 仅为并存权威）。
- **单家漂移点**：结构性例外机制文档单家在 gates.py 头注（py 件将删除）；engine CLI usage 文案、engine/adapters README 与双子树 AGENTS 的命令示例指 `engine/bin.js` / `selftest.mjs` 源形态。
- **基因触点**：`genes/gates/push-precheck-order.json` strategy 引用 `scripts/change-scope.sh`、`genes/gates/new-gene-curation.json` 引用 `node engine/bin.js`——切换后两指针指向不存在路径。
- **延后项到期**：bin.ts pull 不可达窄化 guard（B2 R1 建议）裁决「随 B5/下次触碰 bin.ts」兑现。

## Decision

**单批一次切换（用户既定拍板）：门禁/钩子/CI 执行面全部落 TS 单轨；旧机器件（py/sh/旧 js/mjs 源）全量删除；发版断点 0.2.0。**

1. **gates.json cmd 单源重指**：十条 py 门禁 → `node scripts/verify-*.mts`；`change-scope` → `node scripts/change-scope.mts`（新建，bash 行为恒等端口——输出三段格式、fork-point 自动推导、显式 base/head 两参、`-c core.quotePath=off` 三条 path 命令逐一保持；切换前与 .sh 双跑对账，自动/显式两模式 stdout 逐字节一致）；`ts-typecheck` 不变。条目集与门禁名零变化（C9 口径）。
2. **结构性例外机制单家迁移**：gates.py 头注的四件例外（review-tier per-ref 循环 / review-brief 仅本地 / change-scope 双推导口径 / gene-format 白名单外独立件）全文迁 `scripts/gates.mts` 头注；gates.mts 成为唯一发射器与执行面。`verify-review-tier.mts` 头注消费契约同步（brief 经同族 import `classify`，替换已失效的 py importlib 表述）。
3. **旧机器件全量删除（C1/C13/C14）**：scripts py 13 件 + change-scope.sh + reconcile-b1/b2（临时代件）+ `__pycache__`；engine *.js 10 件；adapters/dsh *.mjs 9 件。删除前终跑证据：reconcile-b1 12 件 0 diff；reconcile-b2 engine 面三件 0 diff（adapter 面差异为已知形态——B4 只在 TS 面加 mounts 节，js 权威面冻结于 B2，非本批回归）。
4. **钩子与 CI 单轨**：lefthook pre-commit 八个 py job 命令切 `.mts`（glob 分域与 staged 门控零变化）；pre-push 编排器 change-scope 展示面切 `.mts`；validate.yml：门禁发射经 `node scripts/gates.mts --run`、self-test 收敛为 TS 单列（14 行）、engine/adapter self-test 仅保留 dist 面。
5. **运行形态收口（当前状态表述）**：engine CLI usage 文案与 README 合同面示例指 `dist/engine/bin.js`；adapters 防火墙自测命令、双子树 AGENTS 的 spawn 合同（`node <包根>/dist/engine/bin.js`）与自测命令同步；adapters 防火墙扫描面改为按运行形态自适应（dist 跑扫 `.mjs`、源跑扫 `.mts`，两种形态下被扫集合非空——原 `.mjs` 固定过滤在源跑形态下会静默空转）。
6. **随批兑现延后项**：bin.ts pull 解析循环不可达窄化 guard 合并（B2 R1 延后项）——`--cache` 缺值的两处同文案 fail 合一、循环内 unreachable `continue` 消除；行为零变化（同消息同退出码）。
7. **基因指针刷新走引擎写路径**：两基因 strategy 文本的 `scripts/change-scope.sh` / `node engine/bin.js` 指针随批更新（评审收口后、发版前经 `solidify` updated 事件入档——基因是入档资产，不走直接改文件）。
8. **发版 0.2.0（release-flow）**：package.json bump、annotated tag `v0.2.0`、npm publish；0.1.4 待出包项（HANDOFF-todos C 条）由本断点一并覆盖。

## Alternatives considered

- **逐条渐进重指**（B5 前先切部分 cmd）：落败——立项拍板单批切换；部分重指制造第二权威面漂移窗口，与「并存期旧件权威 + 一次收口」纪律相悖。
- **change-scope 保留 bash**（唯一 .sh 例外）：落败——C1/C13 验收判据「无 .py/.sh 残留」；bash 退役完整性是本批口径，且端口对账成本（双跑逐字节比对）一次即付清。
- **selftest 沙箱夹具 python3 → node**：落败——engine selftest 与 verify-* self-test 的沙箱夹具（stub-pass.py 等）是沙箱内临时文件、非仓内残留（C1 判据不覆盖）；保持 B1 同迁夹具零改动，避免切换批重写对账基线。运行时前提 = 执行机有 python3（CI ubuntu-latest 预装；本仓门禁面零 python3 依赖）。
- **基因指针保持不动**（严格 C9 字面零 diff）：落败——0.2.0 会携带指向已删路径的注入文本；刷新走 solidify updated 事件是引擎 sanctioned 写路径，属基因内容演化而非机器层漂移（事件轨证据随批落账）。

## Consequences

- **收益**：执行面单轨（hooks/CI/gates/引擎 evaluate 同一 TS 面）；C1/C13/C14 文件面与链路面转绿；CI self-test 步数 24 → 14；门禁面零 python3/bash 依赖。
- **代价**：node ≥22.18 成为门禁硬前提（CI 钉 node 22；本地 dev 同）；engine self-test 沙箱夹具仍依赖执行机 python3（见 Alternatives 第三条）；历史叙事面（journal、implemented ADR 的既有段落、docs/research 调研稿）保留旧文件名引用——历史叙事非当前状态指针，不改写。
