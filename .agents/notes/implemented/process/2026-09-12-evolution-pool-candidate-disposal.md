# Agent Note: 演化轮候选的销账口径——处理完的候选自池件候选节删除，结论家 = 落地件

> Related：兑现 [2026-09-12-evolution-pool-file](2026-09-12-evolution-pool-file.md) Decision 4 的延后项（该件立的触发「首次演化轮落账」于本批到达，其 Consequences「明确缺口」随之关闭）；归集面 [HANDOFF-evolution-pool](../../../../HANDOFF-evolution-pool.md)；步序家 [feature-flow](../../../workflows/feature-flow.md) §4.6；对账点 [session-close](../../../workflows/session-close.md) §3；首次落账的修法 = [2026-09-12-skill-guard-push-pattern-reachability](../bug-fix/2026-09-12-skill-guard-push-pattern-reachability.md)。

## Problem

池件 2026-09-12 立件时把「候选被演化轮吸收之后如何销账（勾账 / 删除 / 迁 ADR）与是否归档」记为**待定**，触发 = 首次演化轮落账。该触发于本批到达：push 面正则候选经用户点名开轮，产出形态是**代码修法**（转变更批），不属池件开列的三类产物（落闸 / 落卡 / 落条目）之内。

销账口径缺席的代价在首次落账就显现：已处理的候选只能留在候选节，「候选」节语义从「未处理项」漂成「未处理 + 已处理」混合——下一次会话按候选节读盘时，会把已修条目当待办读（同型失真 = 待办区必须写清受影响面的理由，`session-close` §4）。

## Decision

1. **销账 = 删除**：演化轮落账后，被处理的候选从池件「候选」节删除；结论家 = 该候选的**落地件**（门禁条目 / 流程卡 / ADR / 变更批的 ADR）。池件「候选」节语义恒 = 未处理项。
2. **不设勾账态**：不引入 `[x]` 式留痕——池件是归集面不是账本；结论与处理痕迹由落地件承载，双留即同一事实两个家（[doc-standards](../../../../docs/method/doc-standards.md) 单源）。
3. **产出形态开放**：候选的落账不限于池件开列的三类产物——**转变更批**（本批先例）同样算；池件条目本就是「待处理 finding」，其修法形态由修法自身决定。
4. **步序落 `feature-flow` §4.6**：增第 4 步「销账（主会话）」；对账点 = `session-close` §3 的 findings 去向核（本会话开演化轮落账的，核池件候选是否已销账）。机器面不在此步：池件自身条数 / 字数预算仍待定（池件「待定」节「池件自身的机器面」一条），判据稳定即立。
5. **处理记录**：本批删除 push 面正则候选；池件「待定」节的销账需求一条关闭，「池件自身的机器面」一条维持待定。

## Alternatives considered

- **勾账**（`- [x] … → <落地件>` 一行，照 HANDOFF-todos 约定）：落败——池件条数 / 字数尚未上闸（「池件自身的机器面」待定），勾账条只增不减会把归集面变成第二本账；且候选的完整结论在落地件，指针不复述 = 零新信息。
- **迁 ADR**（把候选条目整条搬进 ADR）：落败——ADR 已带走候选的全部有效内容（现象 / 根因 / 修法），搬运即复制正文。
- **已处理候选归档到独立件**：落败——首个候选就建归档件 = 对想象中的规模投资；池规模实测见「池件自身的机器面」待定条。
- **维持待定（本批不处置、候选留节）**：落败——候选已在代码修法中解决，留在候选节即把已修项当待办读；待定节的触发条件已明确到达，继续挂 = 规则被无限顺延（同型风险见护栏 ADR 的 Risks）。

## Consequences

- **采用面**：`feature-flow` §4.6 第 4 步；`HANDOFF-evolution-pool.md`（候选删除 + 销账需求待定条关闭）；[池件 ADR](2026-09-12-evolution-pool-file.md) Consequences 的缺口句按现态改写（决定不动）。
- **口径面**：池件「候选」节 = 未处理项；「待定」节 = 尚无口径的需求，触发到达即走一次同口径拍板（本件为先例）。
- **可回溯性**：被删条目原文在 git 历史与落地件（本批 = 修复件 ADR 的 Problem 节）中都在，不引入信息损失。
- **未覆盖（如实记）**：池件自身的条数 / 字数机器面仍无——池规模有实测后再判，本件不预铺（同 [池件 ADR](2026-09-12-evolution-pool-file.md) Alternatives 丁）。
