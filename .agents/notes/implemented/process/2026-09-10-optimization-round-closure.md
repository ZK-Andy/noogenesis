# Agent Note: 胶囊 01 优化轮收口 + 「优化完成」验收口径

Status: implemented

> Provenance：本仓原创（2026-09-10，优化轮收口批）。候选出处：HANDOFF ⏭「优化轮问题池余项」+ 用户 2026-09-10 拍板「按 B 走」并选定验收口径甲。
> Related：[护栏时序 ADR](../../proposed/architecture/2026-09-06-guardrail-defer-trigger.md)（本 ADR 兑现其触发条件的判定口径）+ [评审实质执行对账 ADR](../architecture/2026-09-10-review-execution-reconciliation.md)（② 缓议触发转行动区）+ [B4 挂载接线 ADR](../architecture/2026-09-08-b4-mount-wiring.md) Decision 6（上帝类/文件名契约闸判不立的 durable 家，相关非取代）。

## Problem

优化轮（2026-09-06 开卷）的问题池与方案工作面，在 M1 守卫两批、注释面在环批、架构规范批之后已无「未判定」条目可动，但**收口动作从未执行**：

- 池文档头部仍是「状态：活跃工作文档」——每轮开场都要重读全篇才发现零可动手项（2026-09-10 连续两个会话实例化的摩擦）；
- `HANDOFF.md` ⏭ 仍把「优化轮问题池余项」列为下一步候选，跨会话导航面因此指向一个已完成面；
- 下游两处悬空：护栏 D 条触发 = 「首个胶囊优化完成」，而该 ADR 自认「判定标准模糊——触发时须先拍验收口径」；记忆库线档案页触发节写「排期随优化轮问题池排队」。

另有一处真实悬空引用：`export-docs-inloop` ADR 把 lint 泛化的「判定指针」写成「优化轮 §2.1 状态注」——池文档一旦冻结即成断头引用（触发条件必须自持于 durable 家）。

## Decision

1. **「胶囊 01 优化完成」验收口径**（用户拍板 2026-09-10，三条件同时成立）：

   - ① **池零未判定**：问题池与方案工作面每条都有终态，终态只允许四种——已落地 / 判不立（附判据与触发条件）/ 显式挂起（等用户输入）/ 定案留档（免行动）；收口账每行恰一个终态，复合项拆行；
   - ② **终态单源**：每条终态的理由与触发条件落在 durable 家（ADR / 方法文档 / `HANDOFF-todos.md` 行动区），池文档只留指针；
   - ③ **成果实机生效**：本轮交付机制在装机插件上真机复验命中（在环判据 / 守卫 / 契约块；证据 = 滚动窗与 journal 记录）。

   **明确不计入判定阻塞**：显式挂起项与判不立项的触发兑现——否则口径自我指涉、永不可判完成。

2. **收口执行**：池文档状态行改「已收口（2026-09-10）」+ 冻结面声明（调研档案，收口后不再更新；行动区归还 HANDOFF-todos）；池内六条逐条写终态 + 指针；方案工作面五面标注归宿；新增「收口账」节列出终态与去向。
3. **触发单源修正**：`export-docs-inloop` ADR 的 lint 泛化指针改为自持触发条件（会话内出现跨仓写码场景），并同批删除池文档内同一触发与判不立理由的复述（`§2.1`「规范事前接入」余项三件的明细）——池文档只留指向 ADR 的指针，冻结副本不再成为第二个家。
4. **跨会话遗留转行动区**：显式挂起一件（技能集总结「等等」候选）+ 两件缓议触发（技能 A3 阻断档、评审收口触点提醒）落 `HANDOFF-todos.md`（触发条件与预拍板指针在案）。
5. **护栏 D 条**：触发条件随本口径兑现 → 由「等触发」转「待排期」；护栏建设轮本身不属本批（立项时按护栏 ADR Alternatives 逐件拍板接入形态与验收口径）。

## Alternatives considered

- **不做正式收口（池文档继续挂着）**：落败——零可动手项的「活跃」文档每轮索取开场阅读预算，且 D 条与融合轮排期被未收口的旧轮间接阻塞（2026-09-10 两会话实证）。
- **验收口径取「全部条目落地才算完成」**：落败——三条判不立（上帝类预防闸 / 通用化在环门禁面 / A3 写入前阻断）按 HERO 判据无具体失败可检测，重开只会再判一次不立，口径永不可达。
- **验收口径取「用户宣布制」**：落败——最省事，但护栏 ADR 自认的「无限顺延」风险原样保留，且跨会话无自证证据面。
- **池文档整篇删除、结论只留 ADR**：落败——§3 调研全图（上游协作体系七层 / 命名考据 / HERO 细读 / 零损失搬迁实验）是后续轮次的语料，删除即丢资产；冻结存档成本为零。
- **池条物理删除（只留收口账）**：落败——终态记录（判不立理由 + 触发阈值）是防「同一问题重开」的凭据，删除等于把论证成本推给未来。

## Consequences

- **判定面**：护栏 D 条触发 = 已满足；护栏建设轮 = 待排期。
- **边界**：本批零产品代码；池文档冻结后新增调研另开件（research 层不承载状态）。
